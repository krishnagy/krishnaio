# Personal ML notebook site

Static HTML/CSS. No build step.

1. Push the contents of this folder to the root of your GitHub repo's `main` branch.
2. Settings > Pages > Deploy from branch `main`, folder `/ (root)`.
3. `CNAME` contains `www.krishnaio.com`; delete it if you are not using that domain.
4. Search all files for text highlighted in red with a dashed underline: those are blanks for your real numbers.
5. Replace `you@example.com`, `YOUR-USERNAME`, `YOUR-HANDLE`, and add `resume.pdf`.
6. Rewrite each journal post so it matches what you actually did. Delete projects you have not built.
