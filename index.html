Projects

Each project states the problem, what I built, and what it ran on.

Project 1: Customer churn prediction pipeline

Tabular ML

Problem. Predict which customers are likely to leave, using only information available at prediction time.

Built. A scikit-learn pipeline with a logistic regression baseline and XGBoost, time-based validation, and MLflow experiment tracking. Final PR-AUC value.

Ran on. Python, pandas, scikit-learn, XGBoost, MLflow. Read the journal posts.

Project 2: Image classifier with transfer learning

Computer vision

Problem. Classify images from a small dataset where training from scratch overfits.

Built. A fine-tuned ResNet with staged unfreezing and augmentation, plus an error analysis that surfaced mislabeled data. Validation accuracy value.

Ran on. Python, PyTorch, torchvision. Read the write-up.

Project 3: Support message classifier

NLP

Problem. Route short text messages into categories with imbalanced classes.

Built. DistilBERT fine-tuned with Hugging Face, compared against a TF-IDF baseline with per-class F1. Macro F1 value.

Ran on. Python, Hugging Face Transformers, scikit-learn. Read the write-up.

Project 4: Model serving API

MLOps

Problem. Make a trained model callable by other software and reproducible on another machine.

Built. A FastAPI service with input validation, a health check, tests, and a Docker image that bundles the full pipeline.

Ran on. Python, FastAPI, Pydantic, Docker, MLflow. Read the write-up.
